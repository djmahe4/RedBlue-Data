# RedBlue Dataset

A structured collection of cybersecurity findings extracted from public
penetration testing reports, designed for training and evaluating large
language models on offensive (red team) and defensive (blue team) tasks.

---

## Description

This dataset is automatically generated by the RedBlue pipeline, which
clones public pentesting reports from
[juliocesarfort/public-pentesting-reports](https://github.com/juliocesarfort/public-pentesting-reports),
extracts findings, classifies them, and produces three JSONL files.

---

## Files

| File | Description |
|------|-------------|
| `findings.jsonl` | Full structured finding records (title, description, technical details, recommendation, vuln_type, CWE, OWASP, severity) |
| `red_team.jsonl` | Instruction-tuning records: exploit/attack generation |
| `blue_team.jsonl` | Instruction-tuning records: secure fix / remediation |
| `manifest.json` | Incremental processing state |
| `stats.json` | Run statistics |

---


```bash

pip install -r requirements.txt
python scripts/process_reports.py
```
